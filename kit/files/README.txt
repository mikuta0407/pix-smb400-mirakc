PIX-SMB400 / TU-BUHD100 mirakc キット  (@@VERSION@@)
======================================================================

PIX-SMB400 / Panasonic TU-BUHD100 を、mirakc（Mirakurun 互換の
チューナーサーバー）にするキットです。地デジ・BS・BS4K に対応します。

ソース・詳しい説明:
  https://github.com/mikuta0407/pix-smb400-mirakc


■ 必要なもの
----------------------------------------------------------------------
- PIX-SMB400 または TU-BUHD100 本体と、基板の USB Boot ピンに触れる状態
  （ケースを開けます）
- USB メモリ（FAT32 でフォーマットしたもの。中身は消えます）
- LAN ケーブル（本体を有線 LAN につなぎます。DHCP で IP をもらいます）
- Windows 10 以降、または Linux の PC
- BS4K を見るなら ACAS キー（64 桁の 16 進数）。このキットには入っていません。
  無くても地デジ・BS は見られます


■ 手順
----------------------------------------------------------------------
1. USB メモリに 3 つのファイルをコピーする

   機種に合ったフォルダの中身を、USB メモリの一番上（ルート）にコピーします。
   （このキットを作るときに指定した機種のフォルダだけが入っています）

     PIX-SMB400 なら   USB\PIX-SMB400\ の中の 3 ファイル
     TU-BUHD100 なら   USB\TU-BUHD100\ の中の 3 ファイル

       bootargs.bin
       root_rsa_pub_crc.bin
       initramfs_patched.uimg

   ★ 機種を間違えると LAN が使えず、何もできなくなります。
     本体裏のラベルで型番を確認してください。

   ※ 動作確認は TU-BUHD100 で行っています。

2. USB ブートで起動する

   - 電源を抜いた状態で、USB メモリと LAN ケーブルを本体に挿す
   - 基板の USB Boot ピンをショートしたまま電源を入れる
     （ピンの位置は上の GitHub の元になったプロジェクト
       https://github.com/tsuyopon123/pix-smb400-mirakurun の README の写真を参照）
   - 1 分ほど待つ

   本体の IP アドレスは、ルーターの管理画面（DHCP のリース一覧）などで調べます。

3. インストーラを実行する

   Windows:  install.bat をダブルクリック
   Linux:    端末でこのフォルダに移動して  ./install.sh

   IP アドレスを聞かれるので入力します。ACAS キーを聞かれたら入力します
   （無ければ空のまま Enter）。
   adb が PC に無ければ、Google の公式サイトから自動でダウンロードします。

   ACAS キーは acas_key.txt という名前のファイルに書いてこのフォルダに置いておけば、
   聞かれずにそれが使われます。

   途中で「Bluetooth を無効にしますか？」と聞かれます。おすすめは「はい」です
   （Bluetooth のクラッシュがきっかけで本体が固まったことがあるため）。
   ただし USB を抜いて普通の Android TV として使うときも Bluetooth が使えなくなります。
   戻すときは:  adb -s <IP>:5555 shell pm enable com.android.bluetooth

   「mirakc が起動しました」と出れば完了です。

4. 録画ソフトにつなぐ

   EPGStation などの Mirakurun の URL に  http://<本体のIP>:40772  を設定します。
   番組表がそろうまで数十分かかります。


■ 2 回目以降の起動
----------------------------------------------------------------------
USB メモリを挿したまま電源を入れれば、mirakc が自動で起動します
（Android が起動してから 2 分ほど待ってから起動します）。

インストーラは何度実行しても大丈夫です。新しいキットをもらったときも
同じ手順（USB の 3 ファイルを差し替える → 再起動 → インストーラ）で更新できます。
その場合、本体の config.yml（チャンネル設定）はそのまま残ります。


■ 注意
----------------------------------------------------------------------
- 地デジのチャンネル設定は関東（東京）向けです。他の地域の人や、
  設定を変えたい人は下の「設定（config.yml）を変える」を見てください。
- チューナーは 1 本だけです。同時に 2 番組は録画できません。
- 長期間動かしているとハングすることがあるかもしれません（原因は調査中）。
  応答しなくなったら電源を入れ直してください。
- mirakc が落ちても自動では再起動しません（暴走して本体が起動しなくなるのを防ぐため）。
- USB メモリを抜いて電源を入れれば、元の Android TV に戻ります。
  本体の内蔵ストレージ（eMMC）は書き換えていません。


■ 設定（config.yml）を変える
----------------------------------------------------------------------
このフォルダの  payload\config\config.yml  を編集してから、

  Windows:  コマンドプロンプトでこのフォルダに移動して
            install.bat <IP> -OverwriteConfig
  Linux:    OVERWRITE_CONFIG=1 ./install.sh <IP>

を実行します。本体にあった設定は config.yml.bak-日時 に退避されてから
上書きされ、mirakc も再起動されます。
（-OverwriteConfig / OVERWRITE_CONFIG=1 を付けないと、本体の設定はそのまま残ります）

本体の設定ファイルの場所は  /data/local/tmp/mirakc/config.yml  です。
再起動の瞬間、視聴・録画中の番組は切れます。


■ 自動起動を止めたいとき
----------------------------------------------------------------------
  adb connect <IP>:5555
  adb -s <IP>:5555 shell touch /data/local/tmp/mirakc.disabled

戻すときは  touch  を  rm -f  に変えて実行します。
（adb はインストーラが tools\platform-tools\ に入れたものが使えます）


■ ログの見かた
----------------------------------------------------------------------
  adb -s <IP>:5555 shell tail -50 /data/local/tmp/mirakc.log


■ ライセンス
----------------------------------------------------------------------
payload\bin\ のプログラムはそれぞれのライセンスに従います。
NOTICE と LICENSES\ を見てください。
